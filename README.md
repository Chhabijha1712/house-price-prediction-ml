# 🏠 House Price Prediction using Machine Learning

## 📌 Project Overview
House prices depend on multiple factors such as area, number of bedrooms, bathrooms, location, and amenities.
This project uses Machine Learning regression models to predict house prices accurately.

---

## 🎯 Problem Statement
Manual estimation of house prices is subjective and often inaccurate.
This project builds an ML-based regression system to predict house prices using historical housing data.

---

## 🧠 Machine Learning Approach
- Supervised Learning
- Regression Analysis

---

## 📂 Dataset
- Source: Kaggle
- File Name: Housing.csv
- Target Variable: price

### Features Used
- Area
- Bedrooms
- Bathrooms
- Stories
- Parking
